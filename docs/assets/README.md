# Figure provenance

The SVG files in this directory are repository-native explanatory figures derived from the under-review manuscript. They are not screenshots extracted from the submitted PDF.

- `hrvconformer-overview.svg` summarizes the preprocessing, primary model configuration, and one-hour aggregation implemented in this repository.
- `model-comparison.svg` visualizes the means and standard deviations reported in manuscript Table 4 for ten matched runs on the independent ANSeR1 test cohort.

The comparison whiskers represent one standard deviation, not confidence intervals. Update both the visible values and accessible SVG descriptions if the manuscript results change. Do not relabel these results as journal-published until a version of record is available.
